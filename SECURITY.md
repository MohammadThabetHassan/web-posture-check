# Security policy

web-posture-check is a security tool, so we take problems in it seriously: for example a check that
passes something it should fail, a way to make the tool send requests it should not, or a flaw in how
it handles `--insecure`.

## Reporting a vulnerability

Please report privately through GitHub: open the repository's **Security** tab and choose
**Report a vulnerability**. Do not open a public issue for a vulnerability.

Include what you ran (command and options), what happened, and what you expected. We aim to reply within
a week and will credit you in the changelog unless you prefer not to be named.

## Supported versions

Only the latest release receives fixes.
